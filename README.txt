TECNOLOGIA PARA TODOS

Arquivos
- index.html: estrutura do site
- styles.css: visual responsivo, temas e acessibilidade
- script.js: idioma, modal de leitura, quiz e controles
- content.json: conteúdo dos 25 temas do PDF e dos 8 tópicos de inclusão
- assets/: ícones originais do projeto

Recursos
- Alternância Português/Inglês para interface e conteúdo dos cartões/modal
- Tema escuro
- Aumentar/diminuir fonte
- Alto contraste
- Menu responsivo e link para pular ao conteúdo
- 25 leituras curtas em botões e 8 temas de inclusão
- Quiz com feedback

Imagens
A página utiliza imagens remotas de páginas institucionais (AT&T e UNICEF). É necessária conexão com a internet para carregá-las.
